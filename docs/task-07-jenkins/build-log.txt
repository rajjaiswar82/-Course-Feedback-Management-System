CRITICAL EVIDENCE FOR SCM-TRIGGERED BUILD:
------------------------------------------

"Started by an SCM change"

This proves that the polling trigger detected changes and automatically started the build.

1. build-log-manual.txt (Started by user admin)
2. build-log-scm-trigger.txt (Started by an SCM change)
