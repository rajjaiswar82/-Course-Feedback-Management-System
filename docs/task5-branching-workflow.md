# Task 5 — Feature Development with Branching

Feature: Feedback Submission Workflow

1. Update `dev`.
2. Create `feature/feedback-workflow`.
3. Implement form, server validation, persistence, and list view.
4. Run `mvn clean test`.
5. Commit and push.
6. Open PR with base `dev`, review actual code, address comments, and merge.
7. Capture actual branch, commit, test, review, and merge evidence.

Example commit: `feat: add feedback submission workflow`.

Do not report a pull request, review, merge, or test as completed unless the real repository shows that result.
